Terminal (CLI)

Dasturchilar uchun — kompyuter terminalida ishlang.

terminal
$ git clone https://github.com/zettacodetech/neuraai
$ cd neuraai/backend
$ python -m venv venv && source venv/bin/activate
$ pip install -r requirements.txt

# Bir martalik savol:
$ python cli.py "O'zbekiston haqida gapir"
# Interaktiv suhbat:
$ python cli.py --chat
# Modelni tanlash:  --model fast | think
$ python cli.py --model think --chat
# Rasm yaratish / tahlil / video:
$ python cli.py --gen-image "kosmos"
$ python cli.py --image rasm.jpg
$ python cli.py --gen-video "panorama"
