Terminal (CLI)

Dasturchilar uchun — kompyuter terminalida ishlang.

terminal — neura CLI
# 1) Lokal o'rnatish (Python 3.10+)
$ git clone https://github.com/zettacodetech/neuraai && cd neuraai/backend
$ python -m venv .clivenv && source .clivenv/bin/activate
$ pip install -r requirements.txt

# 2) Interaktiv suhbat (⚡ Tez / 🧠 Aqlli)
$ neura chat
$ neura chat --model think

# 3) Faylni tahlil qilib tuzatish
$ neura fix myapp.py

# 4) AI kod agentlari (OpenCode / Kilo / Aider)
$ neura opencode "Yangi bot yarat"
$ neura kilo "Qidiruv API qo'shish"
$ neura aider -m "README yoz" README.md

# 5) Mahalliy kichik model (internetsiz ishlaydi)
$ neura ollama list
$ neura ollama run qwen2.5
